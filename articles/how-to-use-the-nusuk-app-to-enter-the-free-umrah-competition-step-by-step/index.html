How to Use the Nusuk App to Enter the Free Umrah Competition — Step by Step

What is the Nusuk app? Nusuk is the official app for Umrah and visits to the holy cities, from the Saudi Ministry of Hajj and Umrah. Pilgrims use it for Umrah permits, Rawdah bookings and other visit services. The free Umrah competition also runs inside this same official app.

How competition keys work. You get one free key every day. You can earn more keys with codes: each time you use someone else's NG- code, both of you get a key — you get one, and the person who shared the code gets one too. One simple rule to remember: each pair of people can only swap once, so you cannot use the same person's code again and again.

How to enter a code — step by step:

  • Step 1: Open the official Nusuk app on your phone.
  • Step 2: Tap Start the challenge.
  • Step 3: Open the Keys tab.
  • Step 4: Paste the NG- code in the “Add code to get new key” box.
  • Step 5: Tap Check the code.
  • Step 6: Stay on the Congratulations page — this confirms your new key has been added.

Tip: Codes are case-sensitive. Type or paste the code exactly as it is shown, with the same capital and small letters — for example, NG-7mpjM6vp is not the same as ng-7mpjm6vp.

What does a key do? One key lets you answer one question in the challenge. If your answer is correct, you are entered into that day's draw for a free Umrah trip. More keys simply mean more questions you can answer, and more chances in the daily draws.

Prizes. As announced for the competition, the prizes are 100 Umrah trips and 10,000 Zamzam cartons, with daily winners announced from 1 November 2026. Always check the latest prize and winner details inside the official app, as Nusuk itself makes the announcements.

If a code does not work, do not worry — just try the next code from the list. A code may already have been used, it may have expired, or you and that person may already have swapped once, and each pair can only swap once.

Stay safe: The competition runs only inside the official Nusuk app. EasyNusuk only shares community codes to copy and paste — we never ask for your Nusuk login, password or OTP. If any website or person asks for those, do not share them.
