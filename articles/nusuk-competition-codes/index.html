Nusuk Free Umrah Competition — How Codes and Keys Work

The Nusuk Free Umrah Competition is a free quiz inside the official Nusuk app. It runs from 1 November to 20 December 2026, fifty days in total. Every day one winner is drawn for a free Umrah trip for two, and several winners are drawn for Zamzam water. You enter by answering one Islamic knowledge question a day with a key. Keys are free, and invite codes from other pilgrims give you extra keys. This guide explains how keys work, how to add a code, what the prizes include, and how to avoid scams.

How keys work: You get one free key every day inside the app, in the Games Centre under Free Umrah Competition. The key expires at the end of the day, so use it or lose it. Each key opens one of four question doors: Quran, Seerah, Makkah and the Grand Mosque, and Madinah and the Prophet's Mosque. Answer the question correctly and you are in that day's draw. Extra correct answers add extra chances in the same draw, so more keys mean more entries. You can earn extra keys by swapping invite codes. When you use someone's code, you both get one extra key. When someone uses your code, you both get one extra key too. There is one limit to remember: each pair of people can only swap once. If Nusuk says "The code already has been used", it usually means you and that person have already swapped, so copy the next code instead.

How to add a code: In the Nusuk app, tap Start the challenge and open the Keys tab. Paste the code in the "Add code to get new key" box and tap Check the code. Codes start with NG- followed by eight letters and numbers. Codes are case-sensitive, so copy the code exactly, with no spaces before or after it. Add one code at a time. On EasyNusuk, copy any code from the free codes list at the top of this page and paste it in the app. You can also share your own code with the Add your code button, so other pilgrims can use it and you both earn a key. The codes on this page are public community codes shared by users. They are not verified inside the Nusuk app, and some may already be used or expired, so try the next code if one does not work.

Where your own code is: Open the Nusuk app, go to the Free Umrah Competition, and open Keys. Your code is shown there, starting with NG-. Share it anywhere you like. Every time someone uses it, you both get an extra key.

What the prizes are: The first prize is a free Umrah trip for the winner and one companion of their choice. It includes the Umrah visa, return flight tickets, ten nights of accommodation across Makkah and Madinah, transport and guidance services, and a visit to Al-Rawdah Al-Sharifah. Fifty winners are drawn over the fifty days, so one hundred Umrah trips in total. The prize cannot be transferred to another person and cannot be exchanged for cash. The second prize is blessed Zamzam water. Ten thousand cartons are given away across the competition. Each daily Zamzam winner receives twenty cartons to share with loved ones. Delivery is only to citizens and residents in Saudi Arabia. Winners are announced every day on Nusuk's official accounts, @MyNusuk, and their names appear on the Winners page inside the game in the app. Winners are contacted by email, so keep the email address on your Nusuk account valid and check it while the competition runs. Each person can win once. Winners drawn between 21 and 30 November travel for Umrah in Ramadan, per the competition's own promotion.

Scams to avoid: The competition is free to enter. Never pay anyone for a code or a key, and never pay a person or a Facebook page that promises to enter you. Never share your Nusuk password or any verification code with anyone, not even someone who claims to be from Nusuk support. Confirm every detail inside the official app, not through links forwarded on WhatsApp or social media. If a message pressures you to pay or to share a code quickly, it is a scam. The official competition runs only inside the Nusuk app.

After 20 December 2026: The competition ends on 20 December 2026. This page will be updated the same week to say so. The free codes list on this page will stay only if a new competition is announced.
